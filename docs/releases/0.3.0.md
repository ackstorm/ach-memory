# 0.3.0

- `ach-memory init {claude,codex,opencode,pi,all} [--local]`: one command installs
  the plugin into a host; re-run to update. Claude/Codex go through their plugin
  marketplaces; opencode and pi get an in-process adapter that runs the shared
  `session-start.sh` and the MCP stdio proxy entry in their config.
- `plugins/` ships inside the wheel so `init` works from `uvx` on any machine.

No service change; no production roll.
