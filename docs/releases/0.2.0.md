# 0.2.0

Breaking: Working State is gone.

- Removed `working_state_get`, `working_state_put`, `working_state_delete`
  and the `working_states` table (migration `0002` drops it). Nothing ever
  read the checkpoint: `load_context` did not deliver it, the tools required a
  `workspace_id` no agent could compute, and the host's own compaction summary
  covers the same ground. Twelve tools remain.
- The proxy no longer resolves a workspace id; it injects only the project slug.
- Plugin prose (`SKILL.md`, `activation.txt`, the pre-compact nudge) no longer
  mentions Working State; the subagent activation text is regenerated from
  `activation.txt` (it had drifted in 0.1.4).
- `SPEC.md` drops the Working State layer, tools and table, and the "five more
  built-in mental models" note.
