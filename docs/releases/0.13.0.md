# 0.13.0

- **`retain` returns `similar`:** up to three other valid memories of the same
  bank closest to the new claim, with id, title, type, pin and the first 200
  characters. No score threshold and no LLM: the agent judges. The skill and
  the session-start text tell it what to do without asking the user: the same
  claim, forget one; replaced, forget the old one; more detail on the same
  subject, correct the old one and forget the new one. The search is capped at
  3 seconds; when it fails or is slow the retain answers without `similar`.
  The journal keeps the returned ids, and `docs/similar-effect.sql` measures
  how often a forget or correct on one of them follows within 10 minutes.
- **Where a claim belongs:** a new section in the skill. Tables and inventories
  go in repository files, procedures in AGENTS.md or a skill, a gotcha the
  code already shows is not stored, and a trap fixed at its source is
  forgotten.
- **Projects outside git:** a folder with no git origin names its project in
  an `.ach-memory` file (`project = "<slug>"`), found from the current
  directory upwards and never in or above the home directory. The proxy reads
  it only when there is no `MEMORY_PROJECT` and no origin, so it cannot split a
  repository. `ach-memory project init <name>` writes it, and refuses where an
  origin or a marker already names the project.
- **New tool `list_projects`:** the projects you can read, with slug, purpose
  and memory count. The skill has agents call it in a folder with no project,
  ask the user which one it is, and write the marker.

Server and plugin change. Update the plugin on every host and restart it; until
then agents do not see `list_projects`, `similar` handling or the marker.
