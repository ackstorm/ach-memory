# 0.1.4

Plugin prose and the session-start hook only; the server is unchanged.

- `SKILL.md` says when to retain (when the claim lands, not at compaction)
  and where `project_slug` comes from (the cwd's `origin`, or `MEMORY_PROJECT`).
- `activation.txt` states that a host memory directory is a fallback only
  while this server is unreachable.
- `ach-memory context load` prints a "No project context" notice when the
  directory has no git origin, so the gap is visible at session start.
