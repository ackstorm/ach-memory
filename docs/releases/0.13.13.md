# 0.13.13

- **A plugin installed through ACH works with nothing in the environment.**
  `ach-cli env hydrate` delivers the plugin to machines that have no
  `ACH_MEMORY_*` variables, where the host showed the MCP server as failed.
  The client looks for the service in this order: `ACH_MEMORY_URL`; else, with
  `ach-cli` installed and signed in, the Hub of its default profile at
  `/mcp/ach-memory`, with `ach-cli token` as the credential; else
  `http://localhost:8000/mcp/`.
- **Every host follows that order.** The MCP proxy, the session-start load and
  `ach-memory families` resolve the endpoint in one place, and no host config
  names one. Codex, pi and Antigravity used to stop without `ACH_MEMORY_URL`;
  Claude Code and OpenCode used to go to localhost.
- **A machine with `ach-cli` signed in and no `ACH_MEMORY_URL` reaches the
  Hub, not localhost.** For the compose stack, set
  `ACH_MEMORY_URL=http://localhost:8000/mcp/`.

Deploy: the plugin. The server is unchanged apart from its version.
