# 0.1.1

Fixes found while exercising the 0.1.0 plugin against production.

- `ach-memory context load` (the session-start hook) printed the tool's JSON
  envelope; it now prints the standing context text only.
- `recall` and `list_memories` on a project nobody has retained into answer an
  empty result instead of `PROJECT_NOT_FOUND`, so a fresh repository's first
  session starts clean. `PROJECT_NOT_FOUND` now carries a message.
- `scripts/bench.py` and `benchmarks/`: latency and recall quality over MCP on
  the adversarial corpus; results under `benchmarks/results/`.
