# 0.1.0

First release of the rebuilt ach-memory: a governed, engine-neutral access and
delivery layer for memory engines (see `SPEC.md`). Not compatible with any
previous ach-memory release; there is no migration path and none is planned.

## What ships

- MCP streamable-HTTP server with fifteen tools: `retain` (with `wait`),
  `recall`, `reflect`, `forget`, `restore`, `correct`, `delete_memory`,
  `list_memories`, `get_memory`, `history`, `working_state_get|put|delete`,
  `load_context`, `get_operation`. `/health` is the only other route.
- Stdio proxy for agent hosts (`ach-memory mcp --url …`) built on the `mcp`
  SDK; resolves the project slug from the git origin and the workspace id from
  the repository root, injects both, forwards everything else verbatim.
- `Backend` abstract base class with a Hindsight adapter and an in-memory fake;
  one contract suite runs against both. Adding an engine is one module and one
  factory line.
- Governance kept in ACH: idempotent retain by `operation_id`, journal with
  actor / on-behalf-of / before-after, secret scrub at the retain boundary,
  per-bank serialisation of corrections, deterministic bank ids
  (`user_<id>`, `project_<slug>`), slug history with a `PROJECT_RENAMED` notice.
- Working State per (user, workspace) and bounded standing context from the
  built-in mental models (`user-context`, `project-context`), provisioned in
  the engine at first retain.
- Identity from a JWKS-verified JWT or a platform key resolver; users and
  projects are created on first authorised contact. Operators are configured
  by the identity provider's subject.
- Plugins for Claude Code and Codex (skill, hooks, MCP config) installable from
  this repository; `docs/hosts.md`.
- Helm chart, compose stack with a mock LLM, `make e2e` smoke over every tool.

## Hindsight profile

Banks are provisioned with `retain_extraction_mode=verbatim`; recall reads
`types=["world"]`; the only read-side shaping is a semantic-score floor.

## Not in this release

REST data plane, tenants, metrics, rate limiting, dashboard, expiry,
evidence/trigger fields, dedup across operation ids, directives, documents
API, host installer CLI. See `docs/lessons.md` for why.
