# 0.11.0

- **Session start shows what a project needs, not raw rule lists.** It prints
  the project's purpose word for word, then a briefing built from the notes
  agents saved for that purpose, then the models an agent can load when the
  work calls for them. User Context, Project Context and the verbatim
  constraint and convention lists are gone from session start.
- **New memory type `briefing`.** An agent saves as `briefing` what it wishes
  it had known at the start of a session, for any task in the project. When no
  purpose is stored, session start asks the agent to write one from the
  README or AGENTS.md.
- **Four built-in mental models per project:** `briefing` (session start),
  `traps`, `decisions` and `how-we-work` (on demand). Each reads only its own
  memory types and is rebuilt from them in full.
- **`load_context` takes `model`** to load one of them in full, including the
  rest of a briefing that did not fit.

User Context and Project Context are deleted from each bank at its next
retain. Update the plugin for the new skill text.
