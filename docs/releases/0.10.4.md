# 0.10.4

- **Mental models stop drifting.** A refresh no longer reads the bank's own
  mental models (`exclude_mental_models`), so it summarizes claims instead of
  its previous summary, and it may read up to 12,000 tokens of claims
  (`recall_max_tokens`) where Hindsight's default of 2,048 returned about 20 of
  126.
- **Ready for Hindsight 1.2.** Hindsight 1.x lists mental models without their
  prompt and trigger unless asked; ach-memory asks, so it does not re-PATCH
  every built-in model on every retain.

Server change only; it takes effect on deploy. Existing mental models pick up
the new trigger at their bank's next retain. `recall_max_tokens` is honoured
from Hindsight 0.10.1; on 0.9.2 it is accepted and ignored.
