# 0.13.2

- **`correct` takes a `title`.** It used to replace the text only, so a
  corrected memory kept its old title in the session-start index, still
  stating what the correction undid. The journal records the title before
  and after.
- **Session start says when nothing loaded.** The activation text announces
  the purpose, pins and index; without a credential in the host's
  environment, or when the service does not answer, none of it follows. The
  hook now ends with one line saying ach-memory is not reachable and its
  tools will fail. `ach-memory context load` exits 1 on that failure.

Deploy: the server for `correct`, the plugin for the hook. No migration.
