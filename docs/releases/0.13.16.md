# 0.13.16

- **The skill loads its setup on demand.** `SKILL.md` keeps the usage rules;
  install, update, connection and `UNAUTHORIZED` troubleshooting move to
  `skills/ach-memory/references/setup.md`, read only when needed. OpenCode
  receives the skill as data, so its plugin makes the reference links absolute.
- **OpenCode no longer loads the plugin twice inside this repository.** The
  plugin moves from `.opencode/plugins/ach-memory.js`, a folder OpenCode scans
  in the directory it opens, to `opencode.js` at the root. Inside a checkout
  OpenCode had loaded that copy next to the installed one and refused the
  second as a duplicate plugin id.

Deploy: the plugin. The server is unchanged apart from its version.
