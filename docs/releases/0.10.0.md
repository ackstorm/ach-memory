# 0.10.0

- **Session start delivers stored rules verbatim.** `load_context` now gives
  project constraints, user constraints and project conventions word for word,
  newest first, and adds mental models only if they fit in what is left. Whole
  items only; a closing line names anything left out.
- **The budget fits what Claude Code shows.** `context_budget_chars` drops from
  16,000 to 8,700. Past about 10,000 characters of SessionStart output the host
  keeps a 2KB preview, and the project section was the part that went unseen.

This is a server change: production must roll for it to take effect. Mental
models stay provisioned and refreshing, but a project whose rules fill the
budget will not show them.
