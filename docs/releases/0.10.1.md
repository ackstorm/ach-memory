# 0.10.1

- **A hand-typed repository name no longer splits a project.** When an agent
  passes `project_slug` as a spelling of the current repository, such as
  `ach-memory` or `ackstorm/ach-memory`, the proxy uses the canonical slug on
  `retain`, `recall`, `reflect`, `list_memories` and `load_context`. Other slugs
  still address other repositories. Calls with a `memory_id` and `rename_project`
  keep the slug they were given, and `MEMORY_PROJECT` turns this off.

Proxy change only; it takes effect when the plugin is updated. Existing split
projects are not merged.
