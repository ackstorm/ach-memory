# 0.13.3

- **Session start gets 10 s.** Claude Code and Codex drop all hook output
  when the hook times out. With six sessions starting at once, the 6 s limit
  passed and the sessions started with no context and no warning.
- **Session start is faster: ~3.0 s down to ~1.7 s.** On a one-shot call
  the proxy sends `initialize` first and falls back to `discover` only on
  error. It no longer sends the closing DELETE. It also skips the MCP SDK's
  output check, which listed every tool (17 KB) again on each call: the
  gateway prefixes tool names, so the SDK's cache never matched them.
- **A project nobody has retained into asks for its purpose.** Session start
  printed nothing for it, which looked the same as a failed lookup. It now
  says no purpose is stored and shows 0 memories.
- **Claims may quote a memory id.** The secret scrub took `mem_<32 hex>`
  for a token and rejected the claim.
- **The chart can read the database URL from a Secret.** Set
  `config.databaseUrlSecret.name` (and `key`, default `uri`) instead of
  `config.databaseUrl`. The URL then never appears in the pod spec.

Deploy: the server for the scrub and the chart, the plugin for the hook and
the proxy. No migration.
