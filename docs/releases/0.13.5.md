# 0.13.5

- **A session's first prompt asks for one recall.** On the first prompt of a
  session, the prompt hook injects one instruction: run one `recall` with the
  task in your own words, `scope="all"`, and carry on if its note says nothing
  clearly answers. The hook prints it itself, with no network call, on Claude
  Code, Codex, opencode and pi. The idle retain nudge is unchanged after that.
- **`read_events` records the session.** The proxy sends the host's session id
  on every read (`CLAUDE_CODE_SESSION_ID`, `CODEX_THREAD_ID`, or one per proxy
  process) and hides the field from the agent. On Claude Code and Codex, the
  session-start load and the session's reads share that id.
- **`read_events` keeps the requested slug when it resolves to no project.**
  Agents that send a slug nobody has retained into no longer appear without a
  project.
- **Query text is kept less.**
  - Queries from subjects in `MEMORY_WITHHOLD_QUERY_USERS`
    (`config.withholdQueryUsers`) are logged by length only.
  - Other queries go through the same secret scrub as memory content, as before.
  - Every session start clears query text older than 30 days.
  - Length, relevance and latency stay.
- **`mcp` is capped below 2.4.** The plugin is built from pyproject's ranges,
  not `uv.lock`, and the proxy relies on SDK internals.

Deploy: the server (migration 0007) and the plugin, in either order. An older
server ignores `session_id`; an older plugin sends none.
