# 0.10.2

- **Tools that take a `memory_id` no longer require `scope`.** `forget`,
  `restore`, `correct`, `delete_memory`, `get_memory` and `history` read the
  scope from the memory's retain journal entry when it is left out. A hit from
  `recall` with `scope="all"` is now enough to act on, where agents used to
  guess the scope or fail with `scope: Field required`. The caller's own bank
  must own the memory, so someone else's id returns `MEMORY_NOT_FOUND`. The
  proxy fills `project_slug` for these calls, so a project memory resolves in
  the current repository; a memory in another repository still needs its
  `project_slug`.

Server and proxy change: the server part takes effect on deploy, the proxy part
when the plugin is updated. Calls that pass `scope` behave as before.
