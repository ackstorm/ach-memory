# 0.7.4

- **The idle and pre-compact nudges no longer leak into the reply.** Both
  arrive as ordinary prompt context, so the model read them as something to
  report and answered a bare "Hi" with "Nothing new has landed to retain in
  memory." `activation.txt` bans retrieval narration, but that line covers
  recall, not the hook text that prompts it — and it lands at session start,
  turns away from the nudge it has to suppress. Each nudge now carries its own
  "Internal nudge: act on it, say nothing about it.", in the CLI strings and in
  the shell fallbacks that duplicate them.

No service change; the release is the hook text.
