# 0.7.0

- **Idle retain nudge.** When nothing has been retained for a checkout in 30
  minutes, the user's next prompt carries one reminder to retain whatever
  durable claim has landed -- and then nothing for another 30 minutes in that
  session. The stdio proxy stamps every successful `retain`, so an agent that
  saves as it goes never sees the reminder. It rides into the turn the user
  just started, costing no extra turn: `UserPromptSubmit` on Claude Code and
  Codex, `chat.message` on opencode, `before_agent_start` on pi.
  `ACH_MEMORY_IDLE_INTERVAL` (seconds, default `1800`) tunes it. The `Stop`
  nudge from 0.6.0 is unchanged and independent; a retain it triggers resets
  the idle clock.
- **Session start says what this memory is.** The activation text now opens
  with "This memory replaces your own": ach-memory is the system of record,
  host memory directories and built-in memory features are superseded and not
  to be written to while the server is reachable, and a claim is retained the
  moment it lands. Same text on all four hosts and for subagents
  (`hooks/activation.subagent.json` is generated from `hooks/activation.txt`;
  a test holds them together).
- Codex: the new `UserPromptSubmit` hook needs trusting once (`t` in the
  hooks review), like every other plugin hook.

No service change; the release is the plugin.
