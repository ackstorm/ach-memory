# 0.13.9

- **The MCP server starts on Codex.** Codex expands no `${...}` placeholder in
  a plugin's MCP config and passes the server only the variables `env_vars`
  names, so `uvx --from ${PLUGIN_ROOT} ...` never started and Codex sessions
  had no memory tools. `codex-mcp.json` now runs `sh`, which finds this
  release's copy in the Codex plugin cache and starts the proxy from the
  session folder, which names the project.
- **Antigravity is a supported host.** `agy plugin install
  https://github.com/ackstorm/ach-memory`, or an ACH Environment that delivers
  the plugin natively. The session start injects the standing context and the
  MCP tools work. Installed for the user rather than inside the workspace, the
  MCP server names no project: the agent passes `project_slug` itself.
  Antigravity has no prompt, compaction or subagent event, so those nudges are
  not wired there.

Deploy: the plugin. The server is unchanged apart from its version.
