# 0.13.12

- **Antigravity names the project when ach-memory is installed for the user.**
  Antigravity starts the MCP server in the plugin folder, and a copy under
  `~/.gemini/config/plugins/` sits in no repository, so the server had no
  project and the agent had to pass `project_slug` itself. Antigravity does pass
  the session folder down in `PWD`: `ach-memory mcp --in-pwd`, which
  Antigravity's `mcp_config.json` now uses, moves there before naming the
  project.
- **Every host runs `python -m memory.cli` instead of uv's `ach-memory`
  launcher.** That launcher is a `sh` script, and `sh` resets `PWD` to its own
  folder, which is what kept `PWD` from reaching the server. The MCP servers and
  the hooks of all five hosts start the module the same way. The pi extension
  still removes an `mcp.json` entry of the older shape.

Deploy: the plugin. The server is unchanged apart from its version.
