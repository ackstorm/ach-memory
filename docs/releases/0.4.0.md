# 0.4.0

- `recall` takes `scope="all"`: the user and project banks searched together
  and merged by score, project first on a tie. An agent that does not know
  whether the answer is a personal preference or a project decision no longer
  calls recall twice. `scope="project"` without a slug is still an error; an
  unknown project just drops out of `scope="all"`.
- Agents query memory in English whatever language the conversation uses.
  Measured against production on 2026-09-17: a Spanish query scores under the
  0.60 semantic floor and returns nothing where its English form ranks the
  right claim first at ~0.72. `SKILL.md` and the recall tool description both
  say so.
- `config.recallMinSemantic` (`MEMORY_RECALL_MIN_SEMANTIC`) is exposed in the
  chart, so the floor moves with a chart value and a probe run, not a release.
- `scripts/probe-recall.py`: 23 probes with ground truth read out of the live
  banks, printing each target's score. The regression gate for any floor or
  retrieval change. Baseline 20/23, every hit at rank 1, Spanish 2/4.
- `SPEC.md` records what the probe run closed: the order a retrieval change is
  investigated in (adapter config, ingestion, candidate width, reranker last)
  and three non-goals -- automatic capture, transient task state, and a second
  presentation of a memory (a recall delivers 0-1330 tokens; a per-response
  token budget never binds at this corpus size).
- opencode's adapter loads as an ES module.

Service change: a production roll is required for `scope="all"`.
