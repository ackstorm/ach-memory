# 0.11.1

- **The briefing keeps each note in its own words.** Rephrasing once turned a
  note into its opposite; notes are now merged only when they say the same
  thing.
- **No `model` argument in a session without a project.** `load_context`
  showed it there, and every call with it failed, since models belong to a
  project.
- **The Decisions model keeps the project's preferences.** A shared prompt
  rule told it to drop them.
- The mental model trigger no longer sends `recall_max_tokens`, which
  Hindsight 1.2.1 ignores; each prompt asks recall for 12,000 tokens instead.

Server and plugin change; a patch inside the 0.11.X range rolls out with no
GitOps change.
