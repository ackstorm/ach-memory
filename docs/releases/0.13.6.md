# 0.13.6

- **`delete_memory` and `get_operation` refuse an id that is not one path
  segment.** Both put the caller's `memory_id` or `operation_ref` into the
  engine URL, so a value such as `../<bank>/...` reached another bank's routes
  with the service's engine credential. Anything outside `[A-Za-z0-9_-]+` is
  now `INVALID_REQUEST`, and no request is sent to the engine.

Deploy: the server. The plugin is unchanged apart from its version.
