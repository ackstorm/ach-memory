# 0.8.0

- **No project, personal memory only.** When the stdio proxy resolves no project
  slug (no `MEMORY_PROJECT`, no git `origin`), it now lists a reduced tool set:
  `scope` and `project_slug` leave every schema, `rename_project` is hidden, and
  calls are pinned to `scope="user"`. The `recall` and `load_context`
  descriptions drop their project wording. With a slug, nothing changes.

No service change; the release is the proxy.
