# 0.7.2

- **The idle nudge no longer kills the first prompt of an opencode session.**
  `chat.message` pushed its nudge as `{type, text, synthetic}`, and opencode
  validates every part of the user message in `SessionPrompt.createUserMessage`
  before the request leaves the client: the missing `id`, `sessionID` and
  `messageID` raised a `SchemaError`, then
  `EventV2.InvalidDurableEvent: Expected string aggregate field sessionID`. The
  host rendered that as "unexpected server error" — reproducible on the first
  prompt of a session, the only one the idle clock lets the nudge through, and
  invisible to the gateway, which never saw a request. The part now copies
  `sessionID`/`messageID` from the message it rides in and carries its own id.
  `tests/test_plugins.py` runs the hook under node and asserts the three ids.
- Claude Code, Codex and pi were never affected: they take the nudge as hook
  stdout or as a host message, not as a message part.

No service change; the release is the plugin.
