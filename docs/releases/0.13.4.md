# 0.13.4

- **A hung `context load` ends in time for the hook to say so.** One run in
  about thirty hung on the MCP SDK's 300 s read timeout. The host killed the
  session-start hook at 10 s, and the session started with no context and no
  notice. `context load` now gives up after 8 s, and the proxy's one-shot calls
  use a 5 s client timeout, so the hook prints its "not reachable" line instead.

Deploy: the plugin only. No server change, no migration.
