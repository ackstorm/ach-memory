# 0.13.10

- **OpenCode and pi call the family tools without a project slug.**
  `list_families` and `set_families` declare `project_slug` required; the
  proxy fills it, but listed it as required, and OpenCode and pi refuse a
  call that lacks a required argument before it reaches the proxy. The agent
  had to look the slug up by hand first. The proxy now drops it from
  `required` when it knows the project.
- **Codex passes `XDG_CONFIG_HOME` to the proxy.** `ach-cli token` keeps its
  session there; with a non-default `XDG_CONFIG_HOME` the credential came
  back empty and every call failed with `Illegal header value b'Bearer '`.

Deploy: the plugin. The server is unchanged apart from its version.
