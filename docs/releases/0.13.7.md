# 0.13.7

- **Another user's project no longer takes your own memory down.** A project
  belongs to whoever retained into its slug first. For the next person opening
  the same repository, `load_context` and `recall` with `scope="all"` answered
  `FORBIDDEN`, so the session start delivered nothing, their own pinned
  memories included. Both now serve the caller's own bank and leave the
  project out; the session start says the project is not readable. A recall
  that names the project is still refused.

Deploy: the server. The plugin is unchanged apart from its version.
