# 0.9.1

- **The proxy recognises its tools behind a gateway that renames them.**
  LiteLLM's MCP gateway lists the tools as `ach-memory.retain` and so on, so
  every check the proxy keys on a tool name missed: `load_context` went out
  without the project slug (standing context lost its project section), a
  successful `retain` never reset the idle reminder, and the no-project tool
  set kept `rename_project`. The proxy ships with the server, so it now matches
  listed names against this release's own tool set instead of parsing a
  gateway-specific prefix. The host sees the canonical names; calls go out
  under the name the remote listed.

No service change; the release is the proxy.
