# 0.10.5

- **A missing bank reads as empty again.** On Hindsight 1.2, a bank that was
  never created answers 404, and ach-memory reported it as `INVALID_REQUEST`.
  `load_context` therefore failed for every caller whose user bank does not
  exist yet, such as agents that only write to project banks. `list`, `recall`,
  `reflect` and the mental model read now return empty for such a bank.

Server change only; it takes effect on deploy.
