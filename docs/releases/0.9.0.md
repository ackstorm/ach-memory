# 0.9.0

- **Short-lived credentials through a token helper.** `ACH_MEMORY_TOKEN_COMMAND`
  names a command (e.g. `ach-cli token`) whose stdout is the credential. The
  proxy runs it on every request to the remote, so the ACH Hub's 60-minute JWT
  works for a session of any length. It wins over `ACH_MEMORY_API_KEY`; with
  it unset, the static key behaves exactly as before. A failing helper sends
  no credential rather than a stale one.
- **The proxy starts through the LiteLLM MCP gateway.** The gateway answers
  `server/discover` with -32603; the handshake now falls back to `initialize`,
  so both the proxy and `ach-memory context load` work against
  `https://api.ackstorm.ai/mcp/ach-memory`.

No service change; the release is the proxy.
