# 0.13.19

- **Teams come from ACH's `teams` claim.** Production reads the caller's groups
  from `teams` (every ACH team of the caller; ACH 1.3.7 with `forwardTeams` on
  ach-memory's BackendIdentityPolicy) through `config.auth.jwt.groupsClaim`, so
  a project can be shared with any team its owner belongs to. The sharing
  skill reference no longer tells agents to have a team added to the `grants`
  Environment. A test covers reading groups from a configured claim.

Deploy: the plugin. The server is unchanged apart from its version; the claim
switch is a gitops value.
